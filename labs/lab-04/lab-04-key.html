Pick a single numerical variable and make a histogram of it. Select a reasonable binwidth for it.

# Default histogram (ggplot2 picks a binwidth automatically)
ggplot(starwars, aes(x = height)) +
  geom_histogram() +
  labs(title = "Distribution of Height (default binwidth)",
       x = "Height (cm)", y = "Count")
## `stat_bin()` using `bins = 30`. Pick better value with `binwidth`.
## Warning: Removed 6 rows containing non-finite outside the scale range
## (`stat_bin()`).

You can play with the value of bins via binwidth or bins input parameter inside of the geom_histogram() function. Below is the example of different binwidth.

# Larger binwidth - fewer bars
ggplot(starwars, aes(x = height)) +
  geom_histogram(binwidth = 50) +
  labs(title = "Distribution of Height (binwidth = 50)",
       x = "Height (cm)", y = "Count")
## Warning: Removed 6 rows containing non-finite outside the scale range
## (`stat_bin()`).

# Smaller binwidth - more bars
ggplot(starwars, aes(x = height)) +
  geom_histogram(binwidth = 5) +
  labs(title = "Distribution of Height (binwidth = 5)",
       x = "Height (cm)", y = "Count")
## Warning: Removed 6 rows containing non-finite outside the scale range
## (`stat_bin()`).

It is a very common type of graphic and most tools select a bin size value by default. With a small binwidth (e.g. 5), the histogram shows more bars and reveals finer detail (and some noise/gaps) in the data. With a large binwidth (e.g. 50), the bars are fewer and wider, which smooths the distribution but can hide interesting local structure. Choosing an appropriate binwidth is a balance between showing enough detail and avoiding overfitting to noise.

Also check its impact from here for a different data set.

ggplot(starwars %>% filter(!is.na(gender), !is.na(height)),

  labs(title = "Height Distribution by Gender",

Do you see the purpose of fill = gender input in aes() function ? Remove it and run the same code again.

Boxplot (known as also whisker plot) definition: A boxplot gives a nice summary of one or several numeric variables or sometimes one numerical variable across different categories.

  • The line that divides the box into 2 parts represents the median of the data.
  • The end of the box shows the upper and lower quartiles.
  • The extreme lines show the highest and lowest value excluding outliers.

Here it shows that characters identified as “masculine” tend to have a higher median height compared to “feminine” characters, with somewhat similar spread. There are a few outliers (very tall or very short characters) visible.

Do not confound it with a histogram. See other barplot examples from here

what if we apply, let’s see what happens if we use geom_bar() to a numerical variable, such as height:

ggplot(starwars %>% filter(!is.na(height)), aes(x = height)) +
  geom_bar() +
  labs(title = "geom_bar() applied to a numerical variable (height)",
       x = "Height (cm)", y = "Count")

Note that, when geom_bar() is applied to a categorical variable, it correctly counts and displays the number of observations in each category, producing clean, interpretable bars.

However, when applied to a numerical variable like height, geom_bar() treats each unique numeric value as its own separate category rather than grouping nearby values together. This results in many thin, sparse bars that are hard to interpret and don’t convey the overall shape of the distribution.

For numerical variables, geom_histogram() is the appropriate choice instead.

See another interesting example for a different species vs gender but we need to look at some top species to avoid the messy data visualization result

# Keep only the most frequent species to avoid overcrowding
top_species <- starwars %>%
  filter(!is.na(species)) %>%
  count(species, sort = TRUE) %>%
  slice_head(n = 5) %>%
  pull(species)

# Filtering based on the top_species we defined and keeping complete gender cases (removing NA cases)
starwars_sub <- starwars %>%
  filter(species %in% top_species, !is.na(gender))

# creating the barchart for this new data set 
ggplot(starwars_sub, aes(x = species, fill = gender)) +
  geom_bar(position = "fill") +
  labs(title = "Proportion of Gender within Top 5 Species",
       x = "Species", y = "Proportion", fill = "Gender")

Note that, a stacked/filled bar chart is useful since it lets us compare the relative proportions of a second categorical variable (gender) within each level of the first (species), which works well when one variable has more informative groupings than the other. The chart shows that for most of the top species (e.g., Human), there is a mix of masculine and feminine characters, with masculine characters being more common overall.

Exercise 8

Pick two numerical variables and two categorical variables and make a visualization that incorporates all of them and provide an interpretation with your answer.

  • We can think about the height and mass (numerical) along with gender and species (categorical) into a single visualization.

One option can be a scatter plot with color mapped to species, shape (or facet) mapped to gender, creating multiple small-multiple plots via facet_wrap().

# the workflow seems like using the top_species info again 
starwars_sub2 <- starwars %>%
  filter(species %in% top_species, !is.na(gender), !is.na(height), !is.na(mass))

ggplot(starwars_sub2, aes(x = height, y = mass, color = species)) +
  geom_point() +
  facet_wrap(~ gender) +
  labs(title = "Height vs Mass by Species, faceted by Gender",
       x = "Height (cm)", y = "Mass (kg)", color = "Species")

This visualization combines four variables at once: height and mass on the x/y axes, species encoded by color, and gender used to create separate figure panels (facetting).

  • We can see that most characters cluster at lower mass values with a wide range of heights, except for a few very high-mass outliers

  • The faceting by gender allows us to compare whether the height-mass relationship differs between masculine and feminine characters — what do you see from the created visual ?

  • This kind of multi-variable plot is powerful for spotting patterns across several dimensions at the same time, however a care must be taken not to overcrowd the plot with too many categories! (this was the motivation of looking at top5 species only here)
