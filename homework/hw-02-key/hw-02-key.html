The data visualisation was generated using the following code:

data_5k_10k %>% 
  filter(!is.na(gender)) %>%
  mutate(
    pace_minkm = elapsed.time..s./60/(distance..m./1000),
    gender = case_when(
     gender == "M" ~ "Male runners",
     gender == "F" ~ "Female runners"
   ),
   event = fct_relevel(event, "5k", "10k")

  ggplot(aes(x = event, y = pace_minkm)) + 
  geom_boxplot() + 
  facet_wrap(~gender)+
  labs(
     x = "",
     y = "Running pace (min/km)",
     title = "Strava runners pace in 5K and 10K events"
  )

Exercise 3

Question

Recreate the above data visualisation by using suitable ggplot workflow

Answer

First, we identify long-distance and short-distance runners. By merging (with left_join) we only include runs from athletes that are classified as either long-distance or short-distance runners.

strava_runs <- strava_runs %>%
  mutate(distance_km = distance..m./1000,
         speed_ms = distance..m./elapsed.time..s.)

runs_long_vs_short <- strava_runs %>%
  group_by(athlete) %>%
  summarise(
    avg_dist = mean(distance_km, na.rm = TRUE)
  ) %>%
  mutate(
    long_runner = case_when(
      avg_dist > 13 ~ TRUE,
      avg_dist < 7  ~ FALSE,
      TRUE          ~ NA
    )
  ) %>%
  filter(!is.na(long_runner)) %>%
  select(athlete, long_runner) %>%
  left_join(strava_runs, by = "athlete")

We now reproduce the image:

runs_long_vs_short %>%
  mutate(
    runner = case_when(
      long_runner == TRUE ~ "Long-distance runner",
      long_runner == FALSE ~ "Short-distance runner")) %>%
  ggplot(mapping = aes(x = distance_km, 
                     y = speed_ms, 
                     colour = runner))+
  geom_point(alpha = 0.3) +
  geom_smooth(method = "lm", se = FALSE) + 
   scale_colour_manual(values = c(
     "Long-distance runner" = "orange",
     "Short-distance runner" = "forestgreen")) + 
   theme_minimal() + 
   theme(legend.position = "bottom") +
   labs(
     x = "Run  distance (km)",
     y = "Run average speed (m/s)",
     title = "Speed vs Distance for Long- and Short-Distance Runners",
     subtitle = "Grouped by runners' average distance: >13 km vs <7 km",
     colour = ""
   )

Comment: This visualization demonstrates that runners who are, on average, short-distance runners tend to have lower speeds compared to long-distance runners. As short-distance runners increase their run distance, their speed decreases more sharply, whereas long-distance runners tend to maintain a more constant speed across a wider range of distances.

Question

Now the goal is to compare male and female runners based on average values after removing all missing values in the gender variable.

  1. For each gender, calculate the mean distance (in km), and the mean elapsed time (in minutes). Create two side-by-side bar charts: one showing the mean distance and one showing the mean elapsed time for each gender. The bars should filled with different colors based on the gender information. (3 pts)

  2. Provide a brief comment about what you have seen in the mean distance and elapsed time for each gender. (2 pts)

Answer

First we need to get related mean values based on distance..m. and elapsed.time..s. by suitable transformation, from meters to km and seconds to minutes respectively. For the practical purposes, we can apply pivot_longer() to use later the same data frame in a new format for data viz.  While faceting with geom_col() function to create bar charts, scales = “free_y” is essential since the two measures are in different units (km vs minutes), so a shared axis would distort the comparison.

gender_summary <- strava_runs %>%
  filter(!is.na(gender)) %>%
  group_by(gender) %>%
  summarise(
    mean_dist_km  = mean(distance..m. / 1000, na.rm = TRUE),
    mean_time_min = mean(elapsed.time..s. / 60, na.rm = TRUE)
  )

gender_summary <- gender_summary %>%
  pivot_longer(
    cols = c(mean_dist_km, mean_time_min),
    names_to = "measure",
    values_to = "value"
  ) 

gender_summary %>%
  ggplot(aes(x = gender, y = value, fill = gender)) +
  geom_col() +
  facet_wrap(~ measure, scales = "free_y",
             labeller = as_labeller(c(mean_dist_km  = "Mean distance (km)",
                                      mean_time_min = "Mean elapsed time (min)"))) +
  labs(x = "Gender", y = NULL,
       title = "Mean distance and elapsed time by gender")
